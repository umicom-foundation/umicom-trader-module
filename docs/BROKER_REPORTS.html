Saving broker reports in Umicom Trader

The Interactive Brokers connection window can save received observations as CSV files. CSV is a table format that you can inspect in a text editor or spreadsheet. Each report records the scope and completeness available when you select its export action.

Save a captured report

  1. Open the broker connection window. Connect through your configured TWS or IB Gateway session and request the account or market information you want to inspect.
  2. Open the matching report section: account observations, completed orders, historical bars, streaming bars, scanner results or option definitions.
  3. Select Choose new location.... Choose a folder and a new filename. The selected absolute path appears in the field. You can also type it directly.
  4. Check the selected account, contract and request status, then select the section's Write report button.
  5. Wait for the report status to show success and the destination. Open that file using your preferred viewer.

Understand what was saved

Browsing for a filename does not contact Interactive Brokers, place orders, start subscriptions or write a report. The Write action captures the observations then available. Historical reports are historical data; streaming reports are a captured portion of the stream. Old or incomplete observations retain their flags.

The completed-order report can contain multiple accounts in the captured request scope, even when a different account is selected elsewhere in the window. Account observations are separate provider responses and do not form an atomic portfolio or an official broker statement. Keep exported account files in a location you control.

Recover from a problem

  • The chooser was cancelled: the path stays unchanged.
  • The path was edited while browsing: your newer text wins; choose again if necessary.
  • The filename already exists: choose another name. Reports never replace existing files.
  • The report could not be written: inspect any partial new file and retry with a new filename. A failure does not claim that all bytes reached storage.
  • The window was closed during a write: closing does not undo the write already requested. Inspect its destination before retrying.

The connection inspector and these exports are read-only broker workflows. Exporting a report does not enable order transmission.

Read chart timestamp coverage

The historical and streaming chart summaries now describe the timestamps retained by the connection. A gap is a forward step longer than the requested bar interval. Unobserved intervals count the expected steps strictly between adjacent timestamps. Irregular steps are not exact multiples of the bar interval. Duplicate or backward steps are reported separately.

  1. Connect through the existing Interactive Brokers workflow and request a historical capture or five-second streaming bars for a selected contract.
  2. Read the retained-coverage line beside the chart summary. For streaming data this covers only the rolling retained records, not all bars received earlier.
  3. Check the contract, requested interval, regular-hours choice and market session before interpreting a gap. The existing freshness and completion messages remain relevant.

Closed sessions and sparse trading can produce gaps. The counts do not prove a feed failure, request extra market data, fill missing candles or authorise trading. Exported broker records retain their reported values and order.

Inspect chart values

  1. Open a chart with retained observations and move the pointer across its price area.
  2. Read the data line below the toolbar. O is the opening price, H the highest price, L the lowest price and C the closing price. Volume is the value supplied for that candle.
  3. Read the candle time and the offset. The offset is the distance in milliseconds between the cursor time and the nearest visible candle's opening time. The line shows an observed candle; it does not estimate a trade between candles.
  4. Change the timeframe to inspect the same aggregated candles that the chart draws. Pan or zoom to limit selection to visible candles. Move outside the price plot to clear the observation.

The inspector uses a copy captured when the scene refreshes. A newly received bar appears at the next chart refresh. Zero reported volume stays zero. A gap between timestamps may represent closed sessions or sparse data; the inspector does not fill it. The last candle can still be forming.

Other frontends can use UmiChartCandleInspect from umicom/chart/candle_inspection.h with Umicom::chart. Supply the captured candles and the visible range; check the returned status before using the copied observation. Duplicate timestamps and malformed values are rejected, and an empty range returns no observation. This read operation does not place, amend or cancel orders.

Review a selected price move

Historical and streaming chart summaries include measurements for the selected visible bars when their data is fresh. Adjust visible count and offset to compare another range. Missing volume is labelled unavailable; it is never silently replaced with a partial total. These measurements use display values and do not change the original broker report.

The workspace Chart also supports a two-click captured measurement and copying its evidence. Read Measure candles in Umicom Trader for both workflows and their limits.
