Umicom Trader

Economic and earnings calendars

Trader uses the calendar model and native controls owned by Umicom Framework. Start in guest mode for a file-only review; no brokerage credentials are needed.

  1. Add Economic Calendar from the workspace's tool catalogue, or select the Market Analysis layout.
  2. Choose Import calendar CSV. Use a file in the documented Framework schema, up to 4 MiB and 4096 events.
  3. Search a symbol, company, event or source and apply the filter. Expand Event filters for dates, event type, country, currency and importance.
  4. Select an event to inspect its timezone, reporting period, units, source and observation time.
  5. Resize the event/details divider or dock and float the whole panel using workspace controls. Market quotes do not replace the imported snapshot.

An empty actual or estimate means “Not supplied”. Before/after-market labels do not imply a clock time. The calendar does not connect to a live provider, validate source accuracy or place an order. Snapshot/filter persistence across panel closure is not provided.

The complete CSV schema, a fictional practice file, ownership rules and troubleshooting are in the Framework guide share/umicom/framework/docs/learning/economic-earnings-calendar.html in a full installation, or framework/docs/learning/economic-earnings-calendar.html in Umicom Applications source.

Use date and search shortcuts

Press Enter in the search field to apply it. Choose Today (local date) to set both date limits to your computer’s current date, keeping the other filters. This compares source calendar dates; it does not convert events to your timezone. Clear filters restores all imported events, including when a date or country field contains invalid text.

Cancel a file import

While a file is being read, choose Cancel import to keep the current calendar. Cancellation takes effect before a late result can replace your rows. You can then import another file. Closing the workspace also retires an outstanding import.
