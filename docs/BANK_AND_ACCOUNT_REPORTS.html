Bank and broker account reports in Umicom Trader

Trader uses shared Framework services for two different sources of financial information.

  1. Use Bank transaction reports in the workspace toolbar to import a saved Open Banking JSON response. Select an account and currency, inspect booked and pending movements, and export a private CSV. This window does not log in to a bank.
  2. Use Interactive Brokers to connect to an authenticated TWS or IB Gateway session. Before reading an account, choose an overview, margin report or one-currency cash report. Provider responses stay separate from imported bank data.

Framework’s learning guides explain the supported formats and limits: bank-transaction-reports.html and broker-account-reports.html. Both workflows preserve exact provider amount text, expose incomplete data and require an explicit save location. Neither workflow posts ledger entries or initiates a payment.

Live bank connectivity is still provider-specific work. A saved file is not evidence that consent was granted. Bank passwords and authentication codes belong in the bank or authorised provider’s authentication flow.
