Choosing a session in Umicom Trader

The first screen offers Guest, Paper and Live. These choices select a workspace and a local broker connection. They do not prove that a broker has authenticated you. A local workspace profile is a separate option for saved settings.

Current capability: the main chart workspace uses simulation. The separate broker window can inspect accounts and market information through a local broker session. It is read-only: Umicom Trader does not send, change or cancel IBKR orders through this connection.

Where sign-in happens

Enter broker usernames, passwords and authentication codes in TWS or IB Gateway. The Umicom mode screen has no password or authentication-code field. Its connection plan contains only a mode, program, port and client identifier. The socket API connects to the already authenticated broker program on your computer.

1. Explore without an account

  1. Start Umicom Trader and choose Continue as Guest.
  2. The simulation workspace opens without local registration or broker credentials.
  3. Practise moving panels and reading charts. Sample prices and simulated fills are fictional.
  4. Choosing Guest does not open a broker socket. The separate broker button remains available if you later want to inspect a connection.

2. Prepare a Paper connection

  1. Open TWS or IB Gateway and select your Paper session. Enter your Paper credentials and complete any authentication requested there.
  2. Enable socket API access in that program. Keep its API access read-only for the current Umicom inspector.
  3. Start Umicom Trader. Select the broker program on the welcome screen, then choose Open Paper account.
  4. The simulation workspace and a separate, disconnected Paper broker window appear. Check the program and API port against the broker program's settings.
  5. Choose a client ID that is not already used by another socket client. A client ID identifies a software connection; it is not your username or account number.
  6. Choose Connect read-only. If connected, expand Account, market data and order review. Choose an account reported by this connection before reading its values.

3. Inspect a Live connection

  1. Sign in to the intended Live session in TWS or IB Gateway.
  2. Choose the matching broker program and Open Live account in Umicom Trader.
  3. Check the environment in the broker program itself. A port number, account prefix or local mode label cannot prove the environment.
  4. Read and select the Live acknowledgement in the broker window, then choose Connect read-only.
  5. Reopening a window does not preserve acknowledgement or automatically reconnect. Confirm the session again.

The Live option does not turn the simulated chart workspace into a live execution terminal. Use the broker window's own status and account observations to understand what it has received.

A port is a numbered endpoint used by programs to exchange messages. These are defaults, not a reason to override a deliberately changed broker setting. Umicom connects to 127.0.0.1, the same computer. Changing the broker-program selection resets the default port; check any custom port afterwards.

Local workspace profiles

Choose Local workspace profiles to use the existing saved-profile flow. Its password is a local Umicom password, separate from your broker password. See local profile storage and chart controls.

If a connection does not work

  • Cannot connect: check that the broker program is running, authenticated, allows socket API clients, and uses the displayed port. Another machine's address is not accepted by this adapter.
  • Client ID already in use: disconnect the other client or choose a different positive ID.
  • No account displayed: wait for a ready session and inspect the broker's API messages. Do not invent an account identifier.
  • No prices: account permissions, subscriptions, the contract and exchange, and market hours can affect data. Paper access does not promise real-time data for every instrument.
  • Order buttons do not send to IBKR: this is the current capability boundary. Order review and simulation are not broker execution.

Keep account reports and connection logs private. Review them before sharing; they can contain account identifiers, positions and balances even though the welcome screen does not collect credentials.
