Set exact chart drawing coordinates

Use the chart's Drawing coordinates section when dragging is not precise enough. You can edit the anchors of a trend line, ray, range or zone, or set an exact support or resistance price. An anchor is a point defined by its time and price.

Edit a selected drawing

  1. Open the instrument's chart and select a drawing in its object list.
  2. Expand Drawing coordinates and select Load coordinates. This copies the selected drawing's current values into the form.
  3. Edit the first anchor's time and price. For a line, ray, range or zone, edit the second anchor as needed. Support and resistance use a single level; their second price follows the first, their existing second timestamp is retained, and the second-anchor fields are disabled.
  4. Select Apply coordinates. A changed drawing creates one drawing Undo step. Applying identical coordinates leaves history unchanged.
  5. Inspect the result. Use drawing Undo if needed. Select Save chart separately when you want to store the current chart using the configured chart storage.

Enter time and price

Time fields use whole milliseconds since 1 January 1970 at 00:00 UTC. They accept nonnegative decimal digits only. Keep the loaded timestamp when you only want to adjust a price. Adding 60,000 milliseconds moves an anchor forward by one minute. The form keeps all timestamp digits instead of converting them through a floating-point spin control.

Prices use a decimal point, such as 102.5. Scientific notation such as 1.025e2 means the same value. Do not include currency symbols, grouping commas or spaces. Non-finite values and values outside the supported numeric range are rejected. Loading and applying normal finite values uses enough decimal digits to preserve the stored value.

Lines and rays need different anchor times. Boxes also need different prices so they have visible area. Drawing coordinates describe chart annotations; applying them does not submit orders, change an order draft or arm live trading.

Recover from a rejected edit

Message or situationWhat to do
The selection, drawing or lock changed.Review the selected object and choose Load coordinates again. Your typed fields remain visible until you reload; copy any values you still need first.
The drawing is locked.Unlock it through the existing object controls, then load its coordinates again.
A number is rejected.Check for spaces, commas, signs in the time field, or an out-of-range number. A rejected edit leaves the drawing unchanged.
Coordinates form a flat or zero-width box.Use distinct time and price anchors, then apply again.
The instrument changed while editing.Select the intended instrument and drawing, then reload. An old form cannot redirect an edit to another instrument.

Normal chart refreshes preserve typed fields. Selecting another object does not automatically load it: the explicit Load step makes the object being edited clear. Save and restore keep their existing chart-storage workflow.

For contributors

The controls live in Framework's interactive chart adapter. They delegate to UmiTradingWorkspaceMoveChartDrawing, which checks drawing and instrument identity and records the existing drawing history transaction. Trader hosts the shared control and storage facade. Extend that shared operation when adding geometry rules so mouse movement and exact entry keep the same behavior.
