Strategy Development in Umicom Trader

The Strategy Development workspace is a Trader composition of Framework-owned strategy, replay and research views. Trader does not contain a second strategy engine.

Open the layout

Select the Strategy Development layout. Its strategy panel uses the same Framework strategy projection as the standard trading workspace, while replay and research panels provide evidence around it.

Work in simulation first

Start with the simulation environment, select an instrument and load accepted market evidence. The Strategy view reports the environment and the selected instrument. A visible strategy panel does not grant permission to route a live order.

Develop code in Studio

Strategy source can be written and tested in Umicom Studio using the shared C/Assembly build and debugger services. Trader remains the market/replay host; Studio remains the development frontend; Framework supplies the reusable services used by both.

Reusable product API

UmiUiViewModel *view = NULL;
UmiStatus status =
    umi_trader_runtime_create_strategy_development_view(
        workspace, &view);

The returned model is the Framework strategy view under Trader's Strategy Development identity.

Keep paper, simulation and live environments distinct. Review risk, broker readiness and account state independently before any live-routing work.
