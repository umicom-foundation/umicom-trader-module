Review saved route rules in Umicom Trader

The broker inspector can read the JSON report produced by an IBKR stock route-rule checker. This adds evidence to a full-quantity policy review without changing the trading connection.

  1. Open Paper / Live broker connections.
  2. Expand Full-quantity policy and local liquidity watch, then Saved contract and route rules.
  3. Browse to your saved JSON file and choose Import rule report. Select each route to see its raw TIF entries and order types.
  4. Select and subscribe to the intended quote in the inspector. Set the policy's side, quantity and limit, then press Review policy to compare the saved contract, side and route with that quote identity.
  5. Check the timestamp and currency yourself. A match means identity equality only. FOK advertisement is not proof of order acceptance, account permission, exchange enforcement or a particular commission.
  6. Use Clear imported report to remove the imported evidence from the panel.

Unknown flags remain uninterpreted. Missing or failed metadata stays inconclusive. No AON or minimum-fill support is inferred from size increments. Imported summary booleans cannot override the original rule lists.

The file stays local and is read under explicit size and structure limits. The optional panel requires Framework's complete JSON service. If import fails, confirm that you selected the checker's complete report, not an authentication response or a raw endpoint response. Passwords and authenticator codes belong in IBKR's own login flow. This panel does not open the Client Portal Gateway, run a Python script, submit an order or enable live trading.

The report reader is shared Framework code. Its source and regression coverage live with the broker-connectivity components, so other Umicom products can reuse the same interpretation.
