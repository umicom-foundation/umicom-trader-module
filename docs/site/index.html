User guide: begin with a simulated workstation

Before entering an order, identify the data source and execution environment. A demonstration chart, a paper account and a live broker are different operating modes. Do not infer permission to trade from the fact that an Order Entry panel is visible.

  1. Open the learning or standard workstation layout available in your build.
  2. Select an instrument and inspect the linked watchlist, chart and order controls.
  3. Review account, quantity, order type, required price and risk feedback.
  4. Use simulation only for practice. Check rejected input as well as a valid draft.
  5. Inspect the order, execution and position views for the resulting state; keep fees, cash and reconciliation separate from a displayed price chart.

The source README describes the current composition and links to the workstation capability and runtime-safety guides. Read those before testing a provider. Live routing needs independent operational, permission and reconciliation checks; this introduction does not authorise it.

Support and contribution

When reporting a problem, include the application revision, operating system, exact action and error output. Remove credentials, private account information and personal file content. Use the repository issue tracker for a reproducible defect and the contributor guide for documentation improvements.
