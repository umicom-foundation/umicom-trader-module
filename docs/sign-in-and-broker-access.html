Sign in and connect to Interactive Brokers

Umicom Trader has a local account for saved layouts and an independent broker connection. Local registration does not create an Interactive Brokers account or authorize trading.

Create or use a local account

  1. Choose Create account on the welcome screen. This opens its own form.
  2. Choose a username with 3–48 letters, digits, hyphens or underscores, starting with a letter. Names are case-insensitive.
  3. Enter and confirm a local password. The current verifier accepts 12–256 UTF-8 bytes; non-ASCII characters can occupy more than one byte. Use a separate password from your broker account.
  4. Choose Create local account. Later, use the Sign in page. Switching pages clears password fields.
  5. Choose Continue in Simulator if you do not want a local account.

On Windows builds with SQLite, new local accounts are saved in umicom/trader/local-accounts.sqlite below the operating system's per-user data directory. The database contains the normalized username, a random salt and a PBKDF2-HMAC-SHA256 verifier. It does not contain the password, broker credentials or authenticator codes. Existing native-vault profiles remain in the vault and can still be used. If the database is unavailable, the welcome screen reports the native-storage fallback.

Keep this private database out of Git and shared folders. Backups contain local account information. This implementation currently requires Windows native cryptography for persistent sign-in; other systems keep Simulator available until a secure native adapter is supplied.

Connect your broker account

  1. Open TWS or IB Gateway. Select your intended Paper or Live session and sign in there, including IBKR's two-factor approval.
  2. Enable socket API access in that program and check the configured API port and client ID.
  3. In Umicom Trader, choose Paper account or Live account. These choices prepare the connection window; they do not authenticate or connect automatically.
  4. Check the program, port and requested environment. For Live access, read and confirm the explicit intent before connecting.
  5. Connect, then expand Account, market data and order review to inspect the broker-reported account. A local username, account prefix or port number is not proof of the selected broker environment.

The current connection inspector is read-only. It does not place, cancel or modify orders. Chart order tools prepare local tickets for review and do not, by themselves, authorize transmission to an IBKR account. Live execution qualification remains a separate requirement.

TradingView's broker-hosted authorization screen uses a different integration. Umicom does not imitate that authentication by collecting a password or a two-factor code. See IBKR's TWS and Gateway architecture guide.

Use the compact chart controls

  1. Use the left rail to choose a cursor, trend line, support, resistance, range, liquidity annotation or ray. Hover over a short label for its full purpose.
  2. Use the wheel or the plus/minus controls to zoom, drag with the cursor to pan, and choose Fit / Latest to return to retained data.
  3. Expand Drawings and saved charts to change drawing properties, undo and redo edits, or review saved chart state. Collapsing this section retains those controls and their data.
  4. The main toolbar opens Interactive Brokers, practice tape and cash planning without taking a separate full-width row for every tool.

Simulator candles and the practice tape are fictional. They are not evidence of a market-data subscription or an active IBKR session.
